STAGE 01 // VISION

Depth Camera + Raspberry Pi

Stereo/depth camera mounted at the frame captures viewers in front of the mirror and computes a real-time 2D depth silhouette matrix.

  • • Real-time Person Segmentation
  • • USB-C / UART High-Speed Link
  • • Maps Viewer to Up / Home / Down
STAGE 02 // ORCHESTRATION

MOESH Master PCB (v1.3)

Selects active feed between Raspberry Pi depth stream, onboard ESP32 Bluetooth link, or internal generative presets, broadcasting target angles over dual CAN bus channels.

  • • MCU: STM32H723ZGT6 (LQFP-144)
  • • Wireless: ESP32-WROOM-32E
  • • CAN: Dual TCAN334GDR + Chokes
  • • Auto Return-to-Home (0° Flat)
STAGE 03 // MOTOR DRIVERS

25× MOESH Driver PCBs (v1.4)

Each modular driver board receives CAN frames and drives 25 unipolar stepper motors simultaneously via 13 high-voltage Darlington transistor arrays with eFuse protection.

  • • MCU: STM32H723ZGT6 per board
  • • Drivers: 13× TBD62083AFWG (8-Ch)
  • • Protection: TI VQFN-24 eFuse + XT60
  • • Outputs: 25× PH2.0 6-Pin Headers
STAGE 04 // OPTICS & MOTION

Rotary Lever Arm + Overhead Light

Each tile mounts to a fixed offset bracket on the horizontal 28BYJ-48 motor shaft. Rotating up catches the overhead spotlight; rotating down casts a deep shadow; home stays flat.

  • • Home (0°): Flat Parallel Mid-Tone
  • • Tilt Up (+θ): Faces Overhead Light
  • • Tilt Down (-θ): Self-Shadowed Dark
